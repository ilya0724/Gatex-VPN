# GateX 1.4: компактный главный экран, честный «Авто», переподключение и полная маршрутизация

Дата: 05.11.2026. Заказчик: Илья (владелец GateX VPN). Код: `app/` (Flutter: Android, Windows, Linux) и `core/` (gatex-core, обёртка Xray-core), базовая версия v1.3.0 (тег `v1.3.0`).

## Зачем

GateX-клиент уже работает и Илье нравится, как он выглядит. Мешают четыре вещи:

1. **Главный экран надо листать.** Блок с текстом из панели (`sub.announce`: ник, «Ваша подписка ✅ Активна», «Дней осталось», «Всего трафика») занимает пол-экрана и повторяет карточку подписки. Кнопка включения, статус, сервер и ряд «Кабинет / Поддержка / Сайт» уезжают вниз.
2. **«Авто» выбирает плохо.** Сейчас это балансир Xray `leastPing` по всем серверам подписки (`core/config_builder.dart`). Из России самый быстрый пинг у «🇷🇺 Россия | Игровой», но он выпускает в интернет из России и ничего не обходит.
3. **При смене сети связь пропадает.** При переходе Wi-Fi ↔ LTE (или смене Wi-Fi) VPN остаётся «подключённым», а трафик не идёт.
4. **Нет настройки маршрутизации.** Есть только переключатель «Российские сайты напрямую». Нужна полная настройка, в том числе «VPN только для выбранных приложений» на всех трёх платформах.

Успех: человек открывает приложение на телефоне или ПК и видит всё без прокрутки. «Авто» ни разу не уводит на российский выход. После смены сети интернет возвращается сам за несколько секунд. Илья может настроить, какие приложения и сайты идут через VPN.

## Цели

### 1. Компактный интерфейс и главный экран без прокрутки
- Внешний вид (цвета, три темы «Зелёная / Чёрная / Белая», шрифты, стиль карточек) **не меняется**. Илья отклонил стеклянный и минималистичный редизайны.
- Весь интерфейс становится компактнее: меньше кегль, отступы, высота строк и карточек, размер кнопки включения. Ориентир: примерно на 10–15% плотнее, чем сейчас.
- Главный экран целиком помещается без прокрутки: на телефоне от 640 логических пикселей по высоте, на ПК при высоте окна по умолчанию. Прокрутка остаётся запасным вариантом для совсем маленьких окон, но в обычных размерах не нужна.
- Блок `announce` с главного убирается. На карточке подписки появляется маленькая кнопка ⓘ, которая открывает этот текст в нижнем листе (bottom sheet) или диалоге. *Решение Claude: Илья не возражал.*
- Кнопка включения подстраивает размер под доступную высоту в разумных пределах.
- **ПК (Windows, Linux) — альбомное окно** (решение Ильи 05.11): по умолчанию около 900×560, растягивается. Главный: слева карточка подписки, кнопка, статус, плашка режима маршрутизации, статистика (загрузка, отдача, пинг) и ряд «Кабинет / Поддержка / Сайт»; справа список серверов с пингом, российские серверы приглушены с подписью «не входит в Авто». Настройки: разделы слева (Основные, Маршрутизация, Оформление, О приложении), содержимое справа; маршрутизация в две колонки (программы и готовые наборы / свои правила). Телефон остаётся вертикальным. Превью: `C:\Users\ilyab\.ssh\gatex-app-design\.superpowers\brainstorm\1340-1793908117\content\preview-1-4.html` (телефон) и `preview-pc-landscape.html` (ПК).

### 2. «Авто» без российских серверов и без лишних прыжков
- Серверы, которые выпускают в интернет из России, в «Авто» не участвуют. Вручную их выбрать можно, как сейчас.
- Как определять «российский» — *решение Claude*: по флагу/стране сервера, которую приложение уже определяет (`ui/flags.dart`, `subscription/server.dart`): `RU` = исключить. Если страна не определилась, сервер в «Авто» остаётся. Проверено на живой подписке 05.11: флаг 🇷🇺 только у «🇷🇺 Россия» (213.108.4.54) и «🇷🇺 🎮Россия | Игровой» (72.56.12.122) — оба с российским выходом. Все «🏳 LTE Антиглушилка» (№1–№4) помечены 🇵🇱/🇩🇪 и остаются в «Авто» — на мобильном интернете с белыми списками только они и работают.
- В подписке есть серверный пункт «🇪🇺⚡️ Авто - самый быстрый» (его собирает сервер). В приложении своё «Авто», поэтому этот пункт в список и в пул «Авто» не попадает — *решение Claude*.
- «Авто» не должен скакать между серверами из-за мелкой разницы в пинге: соединения рвутся, у сайтов меняется IP. Он держится за текущий сервер, пока тот жив и не стал заметно хуже лучшего. Конкретный механизм (настройки observatory/балансира Xray, гистерезис, `burstObservatory`, выбор на стороне приложения) — на усмотрение исполнителя.
- На экране видно, через какой сервер «Авто» сейчас идёт (уже есть: «сейчас Германия · 38 мс» и т. п.; если нет — добавить).

### 3. Переподключение при смене сети
- Приложение замечает смену сети (Wi-Fi ↔ мобильная, смена Wi-Fi, сеть пропала и появилась) и восстанавливает связь без участия человека. Цель — интернет возвращается за несколько секунд после появления новой сети.
- Android: `ConnectivityManager.NetworkCallback` в `GatexVpnService` и, где нужно, `setUnderlyingNetworks`. ПК: опрос или системные события смены сети/маршрута по умолчанию.
- Что делать при смене — на усмотрение исполнителя: сбросить соединения ядра, перезапустить ядро с тем же конфигом, переоценить «Авто». Человек видит короткий статус «Переподключение…», а не ошибку.
- Если VPN был выключен, ничего не включается само.

### 4. Полная маршрутизация (новый раздел «Маршрутизация» в настройках)
1. **Режим по приложениям** — на Android, Windows и Linux:
   - «Все приложения через VPN» (по умолчанию, как сейчас);
   - «Только выбранные через VPN»;
   - «Все, кроме выбранных».
   - Android: список установленных приложений с иконками и поиском; реализация через `VpnService.Builder.addAllowedApplication` / `addDisallowedApplication`. Само приложение GateX уже исключено (`addDisallowedApplication(packageName)`) — это сохранить.
   - Windows/Linux: выбор по имени процесса (`chrome.exe`, `telegram`), добавление вручную и, если получится, из списка запущенных программ. Работает через правило маршрутизации ядра по процессу; если текущая версия Xray в `core/go.mod` этого не умеет — обновить ядро или реализовать иначе, на выбор исполнителя. Илье сказано, что на ПК это менее надёжно, чем на Android, и он согласен.
2. **Свои правила для сайтов и адресов:** домен (точный, суффикс, ключевое слово), IP или подсеть → «Через VPN» / «Напрямую» / «Блокировать». Правила идут по порядку, каждое можно включить или выключить, порядок меняется перетаскиванием или стрелками.
3. **Готовые наборы одним переключателем:**
   - «Российские сайты напрямую» — уже есть (`directRu`), переносится сюда;
   - «Блокировать рекламу» — по умолчанию выключен. Сейчас `geosite.dat`/`geoip.dat` в сборку не входят (в коде: «Rules need geo files we do not ship yet»). *Решение Claude:* не тащить полный `geosite.dat`, а при сборке релиза в CI брать `category-ads-all` из v2fly/domain-list-community и вшивать компактный список доменов в приложение (обновляется с каждым релизом).
4. **Импорт и экспорт** набора правил (через буфер обмена или файл) для переноса на другое устройство.

**Правила из подписки не применяются** (решение Ильи): `_panelRules(servers.first.routing, …)` из конфига убрать. Действует только то, что настроил человек.

**По умолчанию** (решение Ильи): все приложения и сайты через VPN, напрямую — только российские сервисы (набор «Российские сайты напрямую» включён). «Блокировать рекламу» выключен, своих правил нет.

**Режим приложений главнее правил для сайтов** — *решение Claude*, чтобы ПК вёл себя как Android: приложение, которое по режиму идёт мимо VPN, всегда идёт напрямую, и правила для сайтов и «Блокировать рекламу» к нему не применяются. На ПК правило по процессу ставится первым после служебных.

**Порядок применения:** служебные правила (адреса самих серверов и локальная сеть напрямую, без них VPN не работает) → свои правила человека → готовые наборы → всё остальное через VPN (или напрямую — для приложений вне VPN по режиму).

### 5. Иконки вместо смайликов
- Решение Ильи 05.11: смайлики в интерфейсе выглядят «как из нулевых». Все иконки интерфейса — один аккуратный единый набор (Material Rounded): кнопки сверху, карточка подписки, ряд «Кабинет / Поддержка / Сайт», статистика, пункты настроек, маршрутизация, трей-меню.
- Флаги серверов — круглые векторные (SVG), а не эмодзи. Для «Авто» — иконка молнии в зелёном круге. Пометка LTE — маленький текстовый бейдж.
- Смайлики остаются в тексте с сервера: announce и **названия серверов**. `✨️`, `💫`, `🏳` в названиях серверов Илья просит оставить («так надо») — убирается только эмодзи-флаг страны в начале, вместо него круглый векторный флаг.
- Набор иконок — тот, что приложение уже использует: Material Icons Rounded (`Icons.*_rounded`), просто единообразно и на своих местах (сейчас часть иконок выглядит криво). Если какие-то иконки нарисованы вручную или эмодзи — заменить на Material Rounded. Превью: `preview-full.html`.

### 5а. Тариф и расшифровка смайликов (решение Ильи 06.11)
- На карточке подписки — надпись тарифа (например «Стандарт (LTE)»). Берётся из первой строки announce «Тариф: …», которую уже добавляет сервер (merge.py: Эконом, Стандарт, Семейный, VIP, варианты «(LTE)», «Пробный (LTE)»). Нет строки — нет надписи.
- Смайлики ✨️ 💫 🏳 в названиях серверов остаются, а под списком серверов — расшифровка, что они значат («🏳 — Обход Белых Списков», «💫 — работает Gemini», «✨ — YouTube без рекламы»), из тех же строк announce, чтобы тексты правились в панели.

### 6. Всё остальное — как в v1.3.0
Решение Ильи 05.11: всё, что не названо выше, остаётся как в текущем приложении. В том числе: заставка «Интернет без стен», три темы «Зелёная / Чёрная / Белая», импорт подписки (вставить из буфера, «Получить подписку в боте»), обновление подписки, «Продлить», экран «Серверы» (сортировка по пингу и по скорости, «Проверить скорость», группа «Для мобильного интернета (LTE)», «Подробнее», «Скопировать для поддержки»), диагностика ошибок сервера, «Журнал», настройки «Подключаться при запуске», DNS, IPv6, «Запускать вместе с Windows», «Сворачивать в трей при закрытии», «Сразу в трей», трей-меню (Открыть GateX / Подключить / Отключить / Выйти), «Удалить подписку с устройства», ссылки «Личный кабинет», «Поддержка», «Сайт», «Канал GateX», проверка обновлений, User-Agent `GateX/<версия>`. Переставлять можно только то, что нужно для пунктов 1–5 (например, «Российские сайты напрямую» переезжает в «Маршрутизацию»).

## Не цели

- Новый визуальный стиль, стекло, новые темы, неоновое свечение.
- iOS и macOS.
- Изменения на серверах, в боте, в панели или в формате подписки.
- Синхронизация настроек маршрутизации между устройствами через сервер.

## Анти-цели (провал, даже если формально работает)

- Главный экран всё ещё надо листать в обычном окне или на обычном телефоне.
- «Авто» хоть раз выбирает российский сервер.
- После смены сети нужно руками выключать и включать VPN.
- Режим «только выбранные приложения» молча пускает остальной трафик через VPN, или наоборот выбранное приложение идёт мимо VPN.
- Сломано то, что работает сейчас: подключение, импорт подписки, темы, трей, автозапуск, обновления, бонус «+14 дней за установку». Бот узнаёт клиент по User-Agent `GateX/<версия>`, его формат менять нельзя.

## Ограничения

- Одна кодовая база Flutter на три платформы. Ядро — gatex-core на Xray-core (gomobile на Android, отдельный процесс на ПК).
- Релиз собирает GitHub Actions (`.github/workflows/app.yml`) по пушу в ветку с `[release]` в сообщении коммита. Версия в `app/pubspec.yaml` — поднять до 1.4.0.
- Скачивание идёт по ссылкам `releases/latest/download/...` (бот, сайт). Имена файлов релиза не менять.
- Старые настройки (`shared_preferences`) пользователей должны пережить обновление; `directRu` переезжает в новый раздел без сброса.
